# 2026-07-26 スタンダードデッキ8種を全部組み直した

社長の指摘「デッキが全部悪い。キャラの並びも含めて」を受けての作業記録。

## 1. 何が壊れていたか

**アクターはスキルを1回使うごとに交代する**。つまり前に出たキャラがその札を撃てないと、
そのターンは何もできない。ところが旧デッキは「そのキャラが撃てない札」だらけだった。

| デッキ | 自分のデッキを撃てる率 |
|---|---|
| 不落の砦 | ディレイア68% / **ビコウ10%** / **ドッソ23%** |
| 竜王の暴食 | ジエンド88% / **パークル13%** |
| 疾風の狩団 | **アイ30%** / オウー79% |
| 氷獄の女王 | **セレーナ35%** / ミルオン61% / ダダ74% |
| 槍衾の陣 | ストミー71% / オルス84% / **セヴン26%** |
| 魔王の柩 | **トランザード42%** / アニマ77% / ヤクビ65% |

**デッキの看板キャラ自身が、自分のデッキの3割しか撃てない**ものまであった。
「カードが弱い」ように見えていた原因はカードではなく、この構造。

### 並び順だけでどれだけ変わるか（カードは1枚も変えずに測定）

| デッキ | 旧の並び | 最良の並び | 差 |
|---|---|---|---|
| 槍衾の陣 | 47.6% | 66.7% | **+19.0** |
| 聖歌隊 | 47.6% | 61.9% | **+14.3** |
| 疾風の狩団 | 31.0% | 38.1% | +7.1 |
| 氷獄の女王 | 73.8% | 78.6% | +4.8 |
| 竜王の暴食 | 4.8% | 9.5% | +4.8 |

8デッキ中7つが最良の並びになっていなかった。先頭が最初のアクターなので、並びは実質デッキの一部。

## 2. 組み直しの方針

1. **まず「全員が撃てる属性」でチームを決める**（どのキャラが前でも手が止まらない）
2. その属性の札を厚く積み、**一番撃てないキャラを助ける札から優先**して入れる
3. キャラ札は各2枚（同名回復）、革の鎧2枚は無条件で腐らないので固定
4. 並び順も総当たりで検証
5. シミュレーターで総当たり戦

実装は `engine/src/sampleDecks.ts`。**各キャラの「撃てる率」が60%前後を下回ったら組み直しのサイン。**

|---|---|---|---|
| 魔王の柩 | 55.0% | **62.9%** | ヤクビ→ディレイア→トランザード |
| 氷獄の女王 | 82.1% | **61.4%** | セレーナ→ボーダン→ミルオン |
| 槍衾の陣 | 61.4% | **60.7%** | ストミー→セヴン→オウー |
| 不落の砦 | 57.1% | **59.3%** | ディレイア→ビコウ→ミルオン |
| 剣聖の一閃 | 57.9% | **55.7%** | クラウディア→オルス→レオン |
| 疾風の狩団 | 26.4% | **50.0%** | アイ→ダダ・ダ・ダ |
| 聖歌隊 | 55.7% | **47.1%** | ハスミール→ソーベルト→フォギア |
| 竜王の暴食 | 3.6% | **2.9%** | ジエンド→セヴン（未解決・下記） |

**勝率の開きが 3.6〜82.1%（80ポイント）から 47.1〜62.9%（16ポイント）になった**（竜王を除く7デッキ）。

変えたキャラ:
- 不落の砦: ドッソ → **ミルオン**（撃てる率が13% → 50%。3人とも50%で揃う）
- 疾風の狩団: オウー → **ダダ・ダ・ダ**（アイと雷・氷が噛み合う。26.4% → 50.0%）
- 魔王の柩: アニマ → **ディレイア**、氷獄の女王: ダダ → **ボーダン**、竜王の暴食: パークル → **セヴン**

## 4. 未解決: ジエンドは今のルールだと成立しない

**ジエンドを入れた構成は、相方・並び・カードを何に変えても勝率4〜6%**だった。

| 構成 | 勝率 | 山札切れ負け |
|---|---|---|
| ジエンド + セヴン | 5.7% | 59% |
| ジエンド + フォギア（回復でデッキ戻し） | 4.3% | 56% |
| ジエンド + ビコウ（木・食樹召喚） | 5.7% | 70% |
| **ジエンド抜き**（セヴン→ボーダン→パークル） | **27.1%** | 31% |

同じ「大型1体＋普通1体」でジエンドをアイに差し替えると 15.6% → 28.1% に上がる。
つまり大型枠のせいではなく、**能力「自分のターンの終わりにデッキから2枚トラッシュ」が原因**。
今の環境は決着の66%が山札切れなので、毎ターン自分の山札を2枚削るのは負け筋を自分で踏んでいる。

### 社長判断（2026-07-26）: **第1弾では直さない**

能力（自傷ミル2）はそのまま。HPだけ 20 に戻し、**第2弾でメタ的に有利になるカードを出して拾う**方針。
つまり竜王の暴食の 2.9% は「今は仕様」であり、第1弾だけで評価しないこと。

第2弾を作る時に効くカードの型（このデッキが欲しているもの）:
- トラッシュを山札に戻す札で、**竜属性か闇属性で撃てる**もの（今ある食樹召喚は木属性でジエンドが撃てない）
- 相手の山札も削る札（山札切れレースを自分有利に反転させる）
- トラッシュの枚数を打点や回復に変換する札（自傷を利益に変える）

なお第1弾のカードだけで検討した対処案（不採用）: 削る枚数を2→1／自傷を利益に変える／相手の山札も削る。
