本人のレビューも「アイ・クラウディアの組み合わせがオーバーパワーすぎて、遅めのデッキが息してない」。

デッキの中身は **AP妨害12枚＋コスト踏み倒し**（アイでドロー+1、クラウディアで開始時2チャージ）:
新たな地平線×4／スタンショック×4／ライトニングセイバー×4／テクノウェイブ×4／スイッチ×4 ほか。

## 3. UXの指摘（★5をくれた外部プレイヤーの5点）と対応

すべてブラウザで実測しながら直した。

1. **相手アクターのHPが自分のカードに隠れる** → 相手側だけHP表示をカードの上へ。実測 −7px → **+98px**
2. **手札がアクターのHP・属性に重なる** → 手札の箱とゾーン列を詰め、自分の陣形を上寄せ。**−6px → +21px**
3. **山札に何が残っているか見たい** → 自分の山札をタップで一覧。種類・コスト順にまとめて表示し
   「本当の並び順ではない」と明記（＝次に引くカードは分からないのでゲーム性を壊さない）
4. **効果を見るのが長押しでは気づけない** → 単押しで拡大するように（長押しも従来どおり）
5. **アクターの順番が分かりづらい** → ①/次/③ のバッジ。順番はエンジンに `actorOrder()` を追加してそこだけを正とした

**ついでに見つけた不具合**: 手札の箱が画面いっぱいに広がっていて、山札・AP・トラッシュのタップを
横取りしていた（山札が押せなかった）。`.my-hand { pointer-events: none }` で解決。

## 4. AIの強化

★2レビュー「敵があんまり攻撃してこない」への対応。

旧 simpleAi は「カードの種類ごとに手書きの採点表」だったため、ドロー・サーチ・AP妨害は
どれも「支援」ひとくくりで **score = 8 - コスト×4** となり、コスト2以上の支援は永久に使われなかった。

新 **searchAi は1手先読み**: 行動を実際にクローン上で試し、盤面を採点して選ぶ。
カードの効果はエンジンが解決するのでAI側に採点表がいらず、新カードを足しても自動で価値を理解する。

- 強さ: **旧AI相手に62%**（`npm run sim -- --mode ai`。seed 1/500/9999 で 62.9/62.1/61.8%）
- 深く読ませる版も試したが逆に弱くなった（1手61.3% → 2手59.2% → 3手58.3%）。
  相手の返しを読んでいないので、深いほど「手札とAPを使い切る線」を過大評価するため。
- 評価の重みで一番効いたのは **AP**（1.5→4 で 60%→67%）。
  ただし最強設定だとAI同士の平均が31.3ターンまで伸びたので、
  相手HPの重みを自分より高く（hpFoe=4.5）して **62%・28.5ターン** に寄せた＝守るより殴る。

### 副作用: 試合が長くなる

同条件のシムで **平均15.2ターン → 28.1ターン**（`npm run sim -- --ai simple` で旧AIと比較できる）。
強いAIほど守りがうまく決着が遠のく。βでは新規2人が1戦目を完走していないので、
これ以上長くしないほうがよい。速さに振り直すなら `engine/src/ai.ts` の `WEIGHTS.hpFoe` を上げる。
