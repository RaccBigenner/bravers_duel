# バトル画面のクオリティ差分と改修計画（2026-07-26）

ポケポケ（Pokémon TCG Pocket）のバトル画面を実際に見て分析し、現在の BRAVER'S DUEL との
差を数字で出したうえで、「変にならない範囲」で効く改修を並べたもの。

参考にしたのは**レイアウトの考え方だけ**。見た目（白基調のマット・カード枠）は真似しない。

---

## 1. ポケポケがやっていること（観察）

### いちばん効いている原則: **画面の端は使い切る。切れてよいものは切る**

- **相手の手札**は画面上端で切れている。カードの下40%くらいしか見えない
- **自分の手札**は画面下端で切れている。上40%くらいしか見えない
- **山札・トラッシュ**は画面の左右端に置かれ、**半分近く画面の外**。しかも縮小せず
  盤面のカードと同じ大きさのまま
- 結果、**画面の中央はほぼ全部「戦っているカード」に使われている**

### その他の特徴

| 項目 | ポケポケ |
|---|---|
| 上部のUIバー | **無い**。左端にハンバーガー1つ、右上に小さなラベルのみ |
| バトル場のカード | 画面幅の **45〜50%** と大きい |
| HP表示 | カード右上に**白フチの巨大な数字**。バーは数字の下に細く |
| ベンチ（控え） | 3枠が横一列。**空き枠も半透明の枠線で常に見せる** |
| マット | 明るい単色＋中央に光。カードとの明暗差が大きく、カードが浮いて見える |
| 操作ボタン | 必要な時だけ画面に出る（常設しない） |

## 2. 現在の BRAVER'S DUEL（実測 / 幅390px）

| 領域 | サイズ | 画面に占める割合 |
|---|---|---|
| 上の情報バー（vs名・T1・メイン・×1・音・？・投了） | 高さ35px | 縦の6% |
| 左右のゾーン列（山札・AP・トラッシュ×2） | **幅45px × 2 = 90px** | **横の23%** |
| 自分の手札の箱 | 高さ102px | 縦の18% |
| 下のアクションバー | 高さ38px | 縦の7% |
| **アクターのカード** | **幅92px** | **横の24%** |

### 差分の要点

1. **主役のカードが小さい。** うち24% ⇔ ポケポケ45〜50%。ほぼ2倍の差
2. **横幅の23%を、ゾーン列（山札・AP・トラッシュ）が両側で食っている。**
   しかも全部が画面内に収まるように縮小されていて、小さくて読みにくい
3. **縦の31%が盤面以外**（情報バー＋手札の箱＋アクションバー）
4. **HPが小さい。** 高さ27pxの中にバー＋「12/12」の極小文字。
   ポケポケは数字だけで30px近くある
5. **空き枠を見せていない**ので、3人のうち誰が倒れたのかが分かりにくい

## 3. 改修計画

「変にならない範囲」で、効く順に並べた。**A〜C は見た目の破綻リスクが低く、効果が大きい。**

### A. ゾーン列を画面端に寄せて、はみ出させる ★最優先

社長の例そのもの。山札・AP・トラッシュを左右の画面端に寄せ、**縮小をやめて半分だけ見せる**。
「山札」「AP」「トラッシュ」の文字ラベルは消し、枚数の数字だけ大きく出す。

- 効果: 横に使える幅が 300px → 370px。**カード幅が 92px → 約115px（+25%）**
- リスク: 低い。位置とサイズの調整だけ
- 注意: タップ判定は画面内に残っている部分で十分取れる（今も38px幅で押せている）

### B. HPを大きな数字にする ★最優先

カードの右上に白フチの大きな数字、その下に細いバー。今の「小さいバー＋極小の12/12」をやめる。

- 効果: βレビューで2回指摘された「HPが見えない」の根本解決。
  かぶって隠れる問題も、数字が大きければ多少重なっても読める
- リスク: 低い。`.char-status` の作り替えだけ
- 補足: 今日の修正で「隠れない」ようにはしたが、**小さすぎて読めない**問題は残っている

### C. 上の情報バーを畳む

常時見せる必要があるのは **ターン数とフェーズ**だけ。
`vs デッキ名`・`×1`・`音`・`？`・`投了` はハンバーガー1つにまとめる。

- 効果: 縦に約30px。カードがもう一段大きくなる
- リスク: 低い。ただし「投了」が1タップ遠くなる（誤タップは減るので、むしろ利点）

### D. 手札を下端で切る前提にする

今は「手札を全部見せる」ために高さ102pxの箱を確保している。
上40%だけ見せて下は画面外に出す。タップで持ち上げて全体を見る（今もある動き）。

- 効果: 縦に約40px
- リスク: **中**。扇レイアウトの角度と持ち上げ量の再調整が要る。
  やりすぎると「カードが読めない」になるので、**Aと B を入れてから様子を見て決める**

### E. 空き枠・戦闘不能枠を見せる

3枠の構造を常に見せる（半透明の枠線）。誰が倒れたかが一目で分かる。

- 効果: 盤面の分かりやすさ。順番（NEXT）とも噛み合う
- リスク: 中。今は「回転する楕円配置」なので、枠を置くと動きと合わない可能性がある。
  **回転演出を残すなら見送り**

### F. フィールドカードの置き場所を直す

今は中央やや左に浮いた `FIELD` の枠がある。左右非対称で座りが悪い。
中央の細い帯に寄せるか、ゾーン列側へ移す。

- 効果: 見た目の整理
- リスク: 低い

---

## 4. やらないほうがいいこと

- **明るい白基調のマットにする** … ポケポケの見た目そのもの。
  社長の「物理的にTCGしてる感じ」「布の卓」の方針と衝突する。
  やるならマットの色ではなく、**カードの縁の明るさ・影を強くしてカードを浮かせる**方向にする
- **カードのデザインを寄せる** … 第1弾144枚の絵と枠を作り直すことになる。割に合わない
- **3Dの傾きをやめる** … ポケポケも奥行きは付けている。今の傾きは強みなので残す

---

## 5. おすすめの進め方

1. **A（ゾーン列を端へ）＋ B（HPを大きく）** をまず入れて実機で見る ← ここで見た目の印象がかなり変わる
2. 良ければ **C（情報バーを畳む）**
3. そのうえでまだ窮屈なら **D（手札を切る）** を検討
4. E・F は余力で

A〜C は既存の演出（踏み込み・被弾・VFX・カット イン）に一切触らないので、
壊れるリスクが低い。各段階ごとに13サイズの自動検査（本日整備）を回して確認できる。
