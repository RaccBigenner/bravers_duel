- 作成日: 2026-07-29
- 対象: 2026-08-26 に開く **G2 Collection Closed Beta**（招待制のテスト。招待した人だけが遊べる）
- 読む人: 社長 Racc
- この文書の目的: 「誰を・何人・どこから呼ぶか」を決めること。実装の話はしない。

## 0. 先に伝えたい大事なこと（前提の訂正）

**「今は誰も遊べない」は正しくありません。すでにNPC戦は遊べます。**

公開URL <https://raccbigenner.github.io/bravers_duel/> は、カード一覧だけのページではなく、
ホーム → デッキ選び → NPC（コンピューター）とのバトル → 結果 まで一通り遊べる状態です
（`web/src/App.tsx` にホーム・バトル・結果の画面があります）。
7月のログでも外部の人が実際に30戦遊んでいます（`docs/balance/2026-07-25_beta_feedback.md`）。

これは集客にとって**とても有利な事実**です。理由は3つあります。

1. 声をかけた相手に「今すぐ触ってみて」と言える。招待βまで待たせなくていい。
2. 宣伝素材（プレイ画面の動画やGIF）を、新しく作らなくても**今日すぐ撮れる**。
3. 「先に遊んで気に入った人」だけを招待βに呼べる。無駄な招待枠を使わずに済む。

なので、この計画は「8/26に一斉に集める」ではなく、
**今から今の公開版で人を集めておいて、その中から8/26に招待する**という形にします。

## 1. G2招待βに何人呼ぶべきか

### 結論

**招待を出す人数は 30〜40人。おすすめは 35人。ただし一度に全部出さず、3回に分けて出す。**

| 波 | 日付 | 人数 | 目的 |
|---|---|---:|---|
| 第1波 | 8/19（本番の1週間前） | 10人 | バグ出し。壊れても被害が10人で済む |
| 第2波 | 8/26（本番） | 15人 | 本番。第1波のバグを直してから |
| 第3波 | 9/2 | 10人 | 予備。集まりが悪ければ増やす、多すぎれば出さない |

### なぜ35人なのか（根拠）

**G2はひとりで遊べるので、人数は「遊べるかどうか」ではなく「意見が集まるかどうか」で決めます。**

G2で完走してほしい流れは、スターター（最初にもらえるカードのセット）を選ぶ →
NPCと戦ってBP（ゲーム内のお金）を稼ぐ → 5枚パックを買う → カード一覧を見る →
ルールに合ったデッキを作る、です（`docs/ONLINE_IMPLEMENTATION_BACKLOG.md` の G2 の条件）。
相手プレイヤーは要りません。だから理屈の上では1人でも成立します。

問題は、**1人や2人の意見では判断できない**ことです。実際に7月の公開βがそうでした。

> ユニーク10人。ただし中身は社長本人＋本気で遊んだ外部プレイヤー1人＋お試し数人。
> 以下の数字はほぼ全部この1人（30戦）なので、傾向のヒントであって統計ではない。
> （`docs/balance/2026-07-25_beta_feedback.md`）

判断に使える意見を得るには、**最後まで遊んで感想をくれる人が10人以上**必要です。
7月の実測から逆算します。

- ホームまで来た9人 → 1戦でも完走したのは3人（**33%**）
- 招待した相手は知り合い経由なので、ただの通りすがりより本気度は高い。
  そこで「招待を受けた人のうち実際に触る人 = 50%」「触った人のうち完走する人 = 60%」と置く
- 35人 × 50% × 60% ≒ **10.5人**

つまり **35人に招待を出して、やっと10人の生の声が取れる**という計算です。
この 50% と 60% は7月の実測（33%）を少し良く見積もった仮の数字なので、
第1波10人が終わった時点で実測に置き換えて、第2波・第3波の人数を決め直してください。

### G3（PvP＝人と人の対戦）に進むには何人要るか

**人数よりも「同じ時間に集まる仕組み」の方が効きます。ここが今回いちばん大事な話です。**

G3の条件は「招待URLか6文字のコードで非公開ルームに入って対戦する」です。
つまり**相手が今この瞬間オンラインにいないと成立しません**。

40人いても、みんなバラバラの時間に来たら、こうなります。

- 40人 × 1日に来る人20% = 1日8人
- その8人が朝から夜まで16時間にバラけると、同じ時間帯にいるのは平均0.5人
- → **ほぼ誰ともマッチしない**

対して、**日時を決めて集める（対戦会）**とこうなります。

- 40人に「9/◯ 21:00から1時間だけ対戦会」と声をかける
- 出席率30%（招待制の身内なら十分ありうる数字）= 12人
- → **6卓が同時に成立する**

必要な最低人数は **同時に8人（4卓）**です。4卓あれば、1人が来なくても他が回り、
「誰とも当たらなかった」という最悪の体験を避けられます。
出席率30%とすると、招待リストは **27人以上**必要。35人ならこの条件も満たします。

**G3では「招待人数を増やす」のではなく「対戦会の時間を決める」ことを先にやってください。**
人数を倍にしてもマッチ率はほとんど上がりませんが、時間を決めれば一気に上がります。

### 少なすぎるリスク（10人以下）

- 意見が1〜2人に偏る。7月に起きたことの再現。1人の好みでカードのバランスを変えてしまう
- G3で対戦相手が見つからない。「誰もいないゲーム」という第一印象がつく。これは取り返しにくい
- バグの種類が偏る。iPhoneだけ、Androidだけ、という報告になり、公開時に別の端末で事故る

### 多すぎるリスク（50人以上）

- **1人運営で支えきれない**。問い合わせ・バグ報告・招待の発行が全部社長に来る。
  返事が遅れると、待たされた人から順に離れる
- **バグが全員に当たる**。直す前に35人全員が同じ不具合を踏むと、直しても戻ってきてくれない。
  だから3回に分ける
- **経済の上限に引っかかる**。設計上、NPCの買取予算は
  「買取可能アカウント数 × 150 BP」と運営が決めた上限（hard cap）の小さい方です
  （`docs/ONLINE_SERVICE_DESIGN_2026-07-29.md`）。
  **招待人数を増やす前に、この上限を必ず更新すること**と設計書に書いてあります。忘れると
  途中でカードが売れなくなります
- **第一印象を使い切る**。呼べる知り合いは有限です。まだ荒いG2で全員使うと、
  本当に見せたいG4（誰でも遊べる公開）の時に呼ぶ人が残りません

## 2. どこで声をかけるか

**注意: ここに書く「見込み人数」は、7月の実測と一般的な感覚からの見積もりです。
外部サービスの利用者数や規約の細かい条件は確認していないので、
「要確認」と書いた所は社長が実際に見て確かめてください。架空のコミュニティ名は一切書いていません。**

### A. 社長の直接の知り合い＋7月のβで遊んでくれた人【最有力】

| 項目 | 内容 |
|---|---|
| 見込み | 5〜10人 |
| 準備するもの | 招待の文（3行）／今の公開URL／連絡手段の確認 |
| 危険な点 | 「付き合いで遊んでくれる」人は本音を言いにくい。感想が甘くなる |

- 7月のβで★5をつけてUX指摘を5点くれた外部プレイヤーが**実在します**。
  この人は最優先で招待すべきです。**ただし連絡先が取れるかは要確認**
  （ログはスプレッドシートに匿名IDで入っており、連絡先は残っていない可能性が高い）。
  連絡先が無いなら、**今の公開版のレビュー欄に「招待βの案内が欲しい人は連絡先を書いてください」
  と一文足す**のが現実的な回収方法です。
- 本音が出にくい問題は、後の「測る数字」で対策します（口で聞かずに行動で測る）。

### B. 紹介制（招待された人に、さらに2枠渡す）【最有力の2つ目】

| 項目 | 内容 |
|---|---|
| 見込み | 5〜15人 |
| 準備するもの | 1人につき2枚の招待コード／誰が誰を呼んだか分かる仕組み |
| 危険な点 | コードが外に流れて、想定外の人数が入る。**上限つきのコードにすること** |

- **TCGを遊ぶ人の友達はTCGを遊ぶ人**です。日本のTCGプレイヤーに届く一番確実な道はこれです。
- 「招待枠を持っている」こと自体が嬉しさになるので、呼ばれた側の本気度も上がります。
- 危険への対策: コードは1回使ったら無効にする、または使用回数の上限を持たせる。
  設計書には招待の受け口（誰を通すかの仕組み）がまだ書かれていないので、**設計が必要です**（→ 3章）。

### C. X（旧Twitter）の社長アカウント

| 項目 | 内容 |
|---|---|
| 見込み | 0〜20人（**読めない**。0もありうる） |
| 準備するもの | 固定ポスト／プレイ画面のGIF／カード画像を使った連続投稿 |
| 危険な点 | フォロワーが少ないと本当に0人。宣伝ばかりだと見られなくなる |

- 7月の実測で **X（t.co）経由の訪問が6人**ありました。**実際に効いた実績のある唯一の外部チャネル**です。
- 一方で「ゲーム内のXシェアボタン経由の訪問は0件」でした。
  つまり**プレイヤーに拡散してもらうのは期待できない**。社長本人の投稿が主力です。
- **手持ちの素材が強い**: カード画像が220枚（公開データのカードは144枚）あります。
  1日1枚カードを紹介する投稿を続けるだけで、絵の力で見てもらえる可能性があります。
  新しく作るものがゼロで始められる、いちばん安いやり方です。
- **要確認**: 社長のXアカウントのフォロワー数／ゲーム専用アカウントを作るかどうか。
  ここが分からないと見込み人数を詰められません。
- 危険への対策: 「宣伝5割・作っている話5割」くらいにする。開発の裏話は宣伝と見なされにくい。

### D. Discord（自分のサーバーを作って受け皿にする）

| 項目 | 内容 |
|---|---|
| 見込み | 新規の集客はほぼ0。ただし**集めた人を留めておく**効果は大きい |
| 準備するもの | サーバー1つ／チャンネル3つ（お知らせ／不具合報告／雑談）／招待リンク |
| 危険な点 | 人が少ないうちに作ると「過疎って見える」逆効果。**20人集まってから作る** |

- **他人のDiscordサーバーで宣伝するのは、この段階では勧めません。**
  多くのサーバーは宣伝を禁止しているか、専用の場所に限っています。
  規約違反で追い出されると、そのコミュニティには二度と入れません。
  **どうしてもやるなら、必ず先に運営に許可を取ること**（規約の細部は要確認）。
- 自分のサーバーは、**G3の対戦会の待ち合わせ場所**として本当に役に立ちます。
  「今から対戦できる人」と声をかけ合える場所がないと、対戦会は成立しません。

### E. ゲーム掲載サイト（ふりーむ！、itch.io など）

| 項目 | 内容 |
|---|---|
| 見込み | **G2では0**。G4（誰でも遊べる公開）向け |
| 準備するもの | （今はやらない） |
| 危険な点 | 招待制のゲームを載せると「遊べないじゃないか」と低評価がつく |

- 掲載サイトは「クリックしたらすぐ遊べる」ことが前提の場所です。
  招待制のクローズドβとは根本的に相性が悪いので、**G2ではやりません**。
- ただし**今の公開版（NPC戦まで遊べる）は載せられます**。
  もしやるなら「招待βの集客」ではなく「今の版のプレイヤー集め」として、8月上旬に別枠で判断してください。
- **要確認**: 各サイトの掲載条件（ブラウザゲームの受け入れ可否、審査の有無、年齢区分）。
  ここは私が確認していないので、断定しません。

### 「ルールの1枚説明」に書くこと（このゲームの売り）

`docs/GAME_RULES.md` を読んで、他のTCGと違う所を3つに絞りました。ここを訴求します。

1. **スキルを使うたびに、戦う人が交代する**
   場に3枠のキャラを並べ、技を1回撃つごとにアクター（前に出ている1人）が
   1→2→3→1と順番に回ります。「誰が・どの順番で・どの属性の技を撃つか」がデッキ作りの中心です。
   これは他のTCGにあまり無い、**このゲームだけの手触り**です。
2. **どのカードでもエネルギーにできる。だから毎ターン「捨てる決断」がある**
   手札のカードはどれでもAPエリアに置いてエネルギーになります（1枚=1AP）。
   手札が5枚以上なら必ず1枚は置かないといけない。**強いカードをエネルギーに変える辛さ**が毎ターン来ます。
3. **相手のターンに割り込める（ガード）**
   攻撃された瞬間、手札からガードの技を出してダメージを減らせます。
   だから「APを攻撃に使い切るか、守りに残すか」の読み合いが常にあります。

添える数字: **カード144枚／キャラ24人／属性17種類／すぐ遊べるデッキ8種類／無料・登録不要でブラウザから**。
（1枚説明の書き方の最終決定は社長。上は素案です）

## 4. 何を測るか（3つだけ）

**「登録した人数」は測りません。** 7月に「ユニーク10人」という数字が出ましたが、
中身は社長本人＋本気の1人＋お試し数人でした。人数は簡単に大きく見えてしまい、判断を誤らせます。

代わりに、**続けて遊んだかどうか**が分かる3つを見ます。

### ① Day2復帰人数（招待を使った人のうち、別の日にもう一度来た人）

- **目標: 12人以上**（招待35人に対して）
- **なぜ**: ゲームがつまらなければ、人は2日目に来ません。感想は気を使って良く言えますが、
  「2日目に来る」は嘘をつけません。**1つだけ選ぶならこれです。**
- ここでいう「別の日」は、初日と暦の上で違う日、という意味です。

### ② 収集ループの完走人数

- **目標: 12人以上**
- **なぜ**: スターター受取 → NPC戦でBP → パック購入 → 合法なデッキ保存、を自力で最後まで、
  というのが **G2の合格条件そのもの**（`ONLINE_IMPLEMENTATION_BACKLOG.md`）。
  これを満たさないとG3に進めません。目標だけでなく**合否のライン**です。
- 途中で止まった人がどこで止まったかも一緒に記録します。7月は
  「ホーム9人 → デッキ選択6人 → バトル5人 → 完走3人」と、どこで落ちたかが分かって大いに役立ちました。

### ③ 1人あたりの対戦回数の**中央値**

- **目標: 中央値5戦以上**
- **なぜ「中央値」か**: 平均だとダメだからです。7月は1人が30戦して他がほぼ0戦でした。
  平均を出すと「1人あたり3戦」に見えますが、実態は「ほとんどの人は0〜1戦」。
  中央値（人数の真ん中の人の値）なら、この嘘を防げます。
- 中央値が5に届かないなら、**面白いのは一部の人にだけ**という意味です。カードやAIより先に、
  最初の1戦の分かりやすさを直します（7月に「新規2人が1戦目を完走していない」という
  未対応の課題が残っています）。

### 3つの合否まとめ

| 数字 | 目標 | 届かなかった時にやること |
|---|---:|---|
| ① Day2復帰 | 12人 | G3に進まず、面白さの見直しを優先 |
| ② 収集ループ完走 | 12人 | G2は不合格。導線とバグを直して再テスト |
| ③ 対戦回数の中央値 | 5戦 | 最初の1戦の分かりやすさを最優先で改善 |

**測る仕組みは既にあります**（匿名IDでのログ収集が稼働中）。招待βでは「招待コード」も
一緒に記録できるようにすれば、誰の紹介から来た人がよく続けているかまで分かります。

## 6. やらないことリスト

| やらないこと | 理由 |
|---|---|
| **大規模な広告（X広告・Google広告など）** | 遊べる人が35人しかいない招待制に広告を打っても、来た人の大半は入れません。お金を捨てるうえに「入れなかった」という悪い印象だけが残ります |
| **インフルエンサー・配信者への依頼** | 一気に大勢が来ますが、**受け入れられるのは35人**です。あふれた分は全部無駄になり、依頼できる人のカードも1回使い切ります。**これはG4（誰でも遊べる公開）で使う切り札**として温存します。今はまだ荒く、悪い印象を広めるだけになる危険もあります |
| **8/26にPvP（人と人の対戦）も一緒に開ける** | G3は「サーバーが正しく試合を管理する・切断から復帰する・相手に手札が見えない」という別の作りが要ります。両方を同時に開けると、**バグが出た時にどちらの問題か分からなくなり**、直すのに何倍も時間がかかります。順番に開けること |
| **ゲーム掲載サイトへの投稿（招待βとして）** | 掲載サイトは「すぐ遊べる」前提の場所です。招待制を載せると低い評価がつき、それがG4まで残ります |
| **他人のDiscordサーバー等での宣伝（許可なし）** | 多くの場所は宣伝を禁止しています。違反すると追い出され、そのコミュニティには二度と戻れません。**許可を取ってからだけ**やること |
| **招待人数を50人以上に増やす** | 1人運営で問い合わせを捌けません。返事が遅い＝見捨てられた、と受け取られます。またNPC買取予算の上限を人数に合わせて上げる必要があり、増やすほど経済の事故が起きやすくなります |
| **プレゼント・景品でつる** | 景品目当ての人はゲームを遊びません。①Day2復帰の数字が景品で膨らんで、**判断そのものが壊れます** |
| **プレスリリース・メディアへの連絡** | 遊べる人が35人の段階では記事になりません。G4で1回だけ使えるカードなので温存します |
| **8/26に間に合わない新機能を足す** | 今は集客より**8/26に確実に開くこと**が優先です。機能追加は9/9の合否判定の後で |
| **感想を口頭で聞いて判断する** | 知り合いは気を使って良く言います。**行動（①②③の数字）で判断すること**。感想は改善のヒントとしてだけ使う |
